🛠️ isset() ka Asli Kaam
Ye function do cheezein check karta hai:

Kya variable banaya (set) gaya hai?

Kya uski value NULL toh nahi hai?

Agar variable bana hua hai aur usme kuch bhi value hai (chahe wo 0, "" khali string, ya false hi kyun na ho), toh isset() kahega TRUE. Agar variable hai hi nahi ya usme NULL bhara hai, toh kahega FALSE.
